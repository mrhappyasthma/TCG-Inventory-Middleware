eBay rejects an Add file without an item location. We send PostalCode only — Location is its alternative, and sending both is a known cause of error 10009.

eBay requires Game on card listings and only accepts values from its own list. SortSwift exports a looser label (e.g. Pokemon) which eBay rejects, so this value overrides the export. Copy it exactly from one of your existing listings. Clear it to fall back to the export's value.

Business policy names, copied exactly from Seller Hub → Account → Business policies. Matching is case-sensitive. Leave blank to omit the column entirely.

eBay requires a CD:40001 (Card Condition) value for ungraded cards. Your SortSwift grade is mapped to one of eBay's four buckets automatically — NM → Near mint or better, LP → Excellent, MP → Very good, HP/DM → Poor. Reports differ on which cell format eBay accepts; switch this if an upload is rejected.

* Value IDs differ by card family. Game/CCG categories use 400010/400015/400016/400017; sports singles (261328) use 400010/400011/400012/400013. The correct table is chosen from your Category ID.
